    - **Spring Boot**: Use constructor injection exclusively; avoid `@Autowired` on fields. Apply layered architecture: Controller → Service → Repository; never skip layers. Use `@Transactional` at the service layer only. Validate inputs with Bean Validation (`@Valid`, `@NotNull`). Use Spring Data JPA repositories; write JPQL or `@Query` for complex queries, never string-concatenated SQL. Externalise all configuration to `application.yml` with `@ConfigurationProperties` binding. Add Actuator and Micrometer for observability.
