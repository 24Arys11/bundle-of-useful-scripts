    - **SQL / Databases**: Always use parameterised queries — never string-interpolated SQL. Design schema with normalisation first, then denormalise with evidence from query plans. Name all constraints explicitly. Keep transactions short; avoid long-held locks. Index based on actual query patterns; verify using the database's query execution plan tool. Use a migration tool for all schema changes — never ad-hoc DDL in production. Separate read and write models where read load is high. Store timestamps as UTC; convert to local time only at the presentation layer.
